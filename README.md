# 🧠 Brain Tumor Detection using Explainable AI & MLOps

## Overview

This project detects brain tumors from MRI images using Deep Learning and Explainable AI (Grad-CAM). It also includes patient symptom analysis, risk assessment, analytics dashboards, and MLOps monitoring.

---

## Features

- MRI Image Upload
- Brain Tumor Classification
- Patient Symptom Scoring
- AI Confidence Score
- Risk Assessment
- Explainable AI (Grad-CAM)
- Patient History Dashboard
- Analytics Dashboard
- MLOps Monitoring
- Streamlit Web Application

---

## Technologies Used

- Python
- TensorFlow
- Streamlit
- OpenCV
- NumPy
- Pandas
- Plotly
- MLflow
